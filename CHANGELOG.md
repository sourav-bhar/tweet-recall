# Changelog

All notable changes to Tweet Recall will be documented in this file.

## [1.0.0] - 2025-02-03

### Added
- Initial release
- Capture tweets as you browse Twitter/X
- Full-text search with fuzzy matching
- Privacy-first: all data stored locally in IndexedDB
- Export tweets as JSON
- Dark mode support
- Works on both x.com and twitter.com
